# Основи CSS — короткий гайд

Цей файл допоможе закріпити базові CSS-властивості, які часто викликають труднощі.  

---

## box-sizing: border-box

### Що робить
Визначає, **як браузер рахує розміри елемента**.

### Чому це важливо
За замовчуванням (`content-box`) `padding` і `border` **додаються** до `width` / `height`, через що елементи стають більшими, ніж очікується.  
`border-box` робить верстку більш передбачуваною.

### Як працює
- `width` включає: `content + padding + border`
- Розміри елементів легше контролювати
- Менше помилок під час верстки макетів

### Рекомендовано
Застосовувати глобально для всього сайту.

```css
* {
  box-sizing: border-box;
}
```

## margin

### Що робить
Відповідає за **зовнішні відступи** між елементами.

### Важливо памʼятати
- Margin **не впливає** на розмір елемента
- Може бути **відʼємним**
- Вертикальні margin між block-елементами можуть **схлопуватись**

```css
margin: 16px;
```

---

## padding

### Що робить
Визначає **внутрішні відступи** між контентом і межами елемента.

### Навіщо потрібен
- Робить контент **читабельнішим**
- Збільшує **клікабельну зону**
- При `box-sizing: border-box` **не ламає розміри**

```css
padding: 20px;
```

---

## display

### display: inline
- Елементи розташовуються **в одному рядку**
- `width` та `height` **не працюють**
- Вертикальні `margin` і `padding` працюють **обмежено**

```css
span {
  display: inline;
}
```

## display: block

- Елемент займає **всю доступну ширину**
- Починається з **нового рядка**
- Працюють `width`, `height`, `margin`, `padding`

```css
div {
  display: block;
}
```

## container

### Що таке container
Контейнер — це обгортка, яка:
- Обмежує ширину контенту
- Центрує його на сторінці

```css
.container {
  width: 1200px;
  margin-left: auto;
  margin-right: auto;
}
```

## :nth-child() — вибір елементів за порядковим номером

### Що робить
Псевдоклас `:nth-child()` дозволяє **вибирати елементи за їхнім порядковим номером** серед сусідніх елементів.

### Таблиця результатів для різних значень

| Значення | Номера елементів | Опис |
|----------|------------------|------|
| `1` | 1 | Перший елемент, є синонімом псевдокласу `:first-child` |
| `5` | 5 | П'ятий елемент |
| `2n` | 2, 4, 6, 8, 10,... | Усі парні елементи, аналог значення `even` |
| `2n+1` | 1, 3, 5, 7, 9,... | Усі непарні елементи, аналог значення `odd` |
| `3n` | 3, 6, 9, 12, 15,... | Кожен третій елемент |
| `3n+2` | 2, 5, 8, 11, 14,... | Кожен третій елемент, починаючи з другого |
| `n+4` | 4, 5, 6, 7, 8,... | Усі елементи, окрім перших трьох |
| `-n+3` | 3, 2, 1 | Перші три елементи |
| `5n-2` | 3, 8, 13, 18, 23,... | Кожен п'ятий елемент зі зміщенням |
| `even` | 2, 4, 6, 8, 10,... | Усі парні елементи |
| `odd` | 1, 3, 5, 7, 9,... | Усі непарні елементи |

### Приклади використання

```css
/* Перший елемент */
li:nth-child(1) {
  color: red;
}

/* Усі парні елементи */
tr:nth-child(even) {
  background-color: #f2f2f2;
}

/* Кожен третій елемент */
div:nth-child(3n) {
  margin-right: 0;
}

/* Перші три елементи */
p:nth-child(-n+3) {
  font-weight: bold;
}
```

---

## Підсумок

- `box-sizing: border-box` — робить верстку простішою  
- `margin` — зовнішні відступи  
- `padding` — внутрішні відступи  
- `margin: auto` — центрування block-елементів  
- `display` — визначає поведінку елемента  
- `container` — база для макетів  
- `:nth-child()` — потужний інструмент для вибору елементів за номером

> 💡 Якщо щось здається складним — це нормально. З практикою все стане на свої місця.
